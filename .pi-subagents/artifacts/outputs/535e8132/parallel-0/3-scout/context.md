## Architecture
- FFI/open path (`frt/src/ffi.rs`) interprets simulator mode and/or env flag into `Simulator`.
- `frt/src/instance.rs` exposes `Xsim { legacy }` variant.
- `frt/src/cosim/mod.rs` opens sim device and constructs `XsimRunner` with combined legacy decision.
- XSIM runner (`frt-cosim/src/runner/xsim.rs`) writes tb/tcl generated by `frt-cosim/src/tb/xsim.rs`.
- `run_cosim.tcl.j2` then emits legacy or current xsim property.
- XO metadata parse (`frt-cosim/src/metadata/mod.rs`) merges kernel XML with parsed register map from control RTL; runner then re-derives binding signal names/ports from argument names when generating tb.
- Bazel-level legacy toolchain entries are present (`xsc_legacy_rdi`, `xsim_legacy_rdi`, `dpi_legacy_rdi_library`) but not directly used by repo-owned target definitions.
